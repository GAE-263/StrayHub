🐾 三個不可妥協的細節

  • 🧱邊框 3–6px 實線，一律 #716053，不用灰階。
  • 🎯陰影完全不模糊：4px 4px 0 0 #716053，這是貼紙感的來源。
  • 🫧圓角 24px，小元件 16px，膠囊用 999px。
⚖️ 現實檢查

這份設計，LINE 做得到多少

Flex 做得到

可實作
  • ✅奶霜底色與巧克力棕文字
  • ✅3–6px 實線邊框（borderWidth）
  • ✅24px 大圓角（cornerRadius）
  • ✅emoji 點綴、進度條、卡片式選項

Flex 做不到

需取捨
  • ❌偏移陰影：Flex 沒有 box-shadow，一種都沒有
  • ❌Fredoka 字型：訊息一律用使用者的系統字
  • ❌虛線分隔、任意背景圖樣
  • 💡替代作法：用厚邊框＋高彩度色塊補回份量感
