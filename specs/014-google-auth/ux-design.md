# Google 登入體驗調整

## 目標與規格

主要使用者為收容所工作人員。登入頁協助進入工作；我的收容所頁協助加入或選擇工作地點；登入設定只服務已有帳密的舊帳號。Google-only 不顯示帳密、綁定／解綁表單，也不需前往設定才可進入收容所。

`/access` 為我的收容所。Google 登入後先於此取得伺服器權限；只有一個有效收容所且沒有加入目標時，登入導流自動設定 context 進工作台，多間則明確選擇。`/account` 僅舊帳密帳號顯示登入設定，Google-only 轉 `/access`。舊 `/account?join=UUID` 轉 `/access?join=UUID`。既有 session、API、授權不變。

管理工作台將散落連結移入右上姓名選單：「我的收容所」、具管理權限時「加入申請」、舊帳號「登入設定」。登入方式以本人 API 判斷，未載入時不顯示設定捷徑。

## 視覺計畫

- 森林墨綠 #19332f、品牌綠 #16745c、晨霧 #f4f8f5、白 #ffffff、苔金 #a86d24、邊界 #d9e5df；衍生狀態色沿用既有 danger／accent-soft。
- 標題：Songti TC／Noto Serif TC 系統宋體，僅品牌敘事使用；操作介面沿用系統黑體。帳號識別等輔助資料用 monospace，收於展開區。
- 登入：左品牌照顧日常敘事，右白色登入卡；手機單欄縮短敘事。以放大的「森」品牌字為辨識元素，不加入無意義統計或裝飾圖表。
- 收容所：名稱、中文角色、單一主要「進入工作台」動作；新申請用真實的「登入／送出／審核」進度，結果與下一步同處。
- 審核：左申請人與日期、右角色與核准；固定連結與複製功能集中在側欄，否決需行內確認以避免誤觸，提供成功回饋。

比較過全頁大量卡片與單純表格：前者使等候頁顯得忙碌，後者對新使用者缺少導引。因此採少量主要卡片搭配有意義的進度，管理員使用密度較高的清單。大型品牌字只用登入頁，其餘畫面保持安靜。
