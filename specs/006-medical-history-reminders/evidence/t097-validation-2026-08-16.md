## 錯誤與限制紀錄

- 環境設定：API 首次啟動缺 JWT key；改用 process-local 暫存測試 RSA key 後完成驗收。這是本機設定問題，不計產品錯誤。
- 自動化工具：native 日期時間輸入未觸發 React state；Computer Use fallback 因本機畫面鎖定不可用。SC-002 因此只標示未判定。
- 產品缺陷：Agenda 分頁漏列已修正並加入防回歸測試；修正後自動化遺漏／誤列均為 0。
- 安全邊界：畸形 Bearer token 原會讓 PyJWT `DecodeError` 逸出；已在 access-token adapter 正規化為 `ValueError`，由既有 dependency 回傳 401，並新增回歸測試。修正後完整 pytest 為 431 passed。
- 正式真人樣本尚未招募；不能以 agent 操作、server latency 或 Playwright 時間取代真人時間。
