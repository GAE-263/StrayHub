# 工作人員真人 Usability 驗收證據

**Feature**：志工日常照護回報與動物近期歷程  
**對應任務**：T255  
**對應成功條件**：SC-006、SC-014  
**Protocol**：[usability-test-plan.md](./usability-test-plan.md)  
**狀態**：尚未執行；本文件為去識別化紀錄模板，不代表真人驗收已通過

## 隱私與填寫規則

- 只使用本機或受控 Demo 的虛構資料。
- 受測者只能使用 `S01`、`S02` 等去識別化代碼；不得填入姓名、LINE User ID、電話、電子郵件或其他直接識別資料。
- 所有失敗、接受協助、中途退出與重測紀錄都必須保留，不得刪除或只留下成功樣本。
- 自動化測試或主持人代操作不得填入主要操作次數或狀態辨識結果。
- 若發生環境故障，原始紀錄標記為系統／環境因素；修復後的重測須另列一筆並保留兩者關係。

## 固定測試條件

- 受測者未參與本 Feature 設計或實作，且每位受測者使用相同管理介面、虛構資料與任務說明。
- 指定動物近 14 日資料必須包含「當日無回報」、「未觀察」、「無法判斷」與「AI 處理失敗」四種狀態。
- 近 14 日資料也必須保留同日兩筆回報，供主持人確認同日多筆可個別查看。
- 主要操作定義：造成頁面、路由或主要內容面板切換的一次點擊或觸控；輸入搜尋文字、捲動與展開同頁細節不另計。
- SC-006 的兩秒摘要結果須使用工具或瀏覽器紀錄輔助，不得由主持人主觀估計取代。
