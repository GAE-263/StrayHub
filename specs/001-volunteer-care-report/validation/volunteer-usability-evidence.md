# 志工真人 Usability 驗收證據

**Feature**：志工日常照護回報與動物近期歷程  
**對應任務**：T254  
**對應成功條件**：SC-001、SC-002  
**Protocol**：[usability-test-plan.md](./usability-test-plan.md)  
**狀態**：尚未執行；本文件為去識別化紀錄模板，不代表真人驗收已通過

## 隱私與填寫規則

- 只使用本機或受控 Demo 的虛構資料。
- 受測者只能使用 `V01`、`V02` 等去識別化代碼；不得填入姓名、LINE User ID、電話、電子郵件或其他直接識別資料。
- 所有失敗、接受協助、中途退出與重測紀錄都必須保留，不得刪除或只留下成功樣本。
- 自動化測試或主持人代操作不得填入「獨立完成」或取代真人結果。
- 若發生環境故障，原始紀錄標記為系統／環境因素；修復後的重測須另列一筆並保留兩者關係。

## 固定測試條件

- 受測者未接受本系統專門訓練，且未參與本 Feature 設計或實作。
- 每位受測者使用相同的標準 LINE Bot 回報情境與虛構資料。
- 必須完成動物確認、13 個結構化題目、摘要確認與正式送出。
- 照片與心得為選填；不得因略過照片或心得判定失敗。
- SC-002 計時從 Bot 顯示第一個可操作問題開始，到顯示正式 Care Report 保存成功為止；AI 處理時間不計入。
