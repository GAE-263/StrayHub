# UI Behavior Contract：觀察詞彙管理

本契約把 [spec.md](../spec.md) 的使用者可觀察行為轉成前端實作與驗收邊界。元件名稱可調整，但下列語意、文字層級、角色能力與狀態不可省略。

## 角色能力

| 角色 | 可查看 | 可新增／編輯／排序 | 可停用／恢復／封存 |
| --- | --- | --- | --- |
| `SHELTER_ADMIN` | 目前收容所完整有效與歷史詞彙 | 本收容所自訂 | 本收容所自訂 |
| 有效 Shelter Context 的 `PLATFORM_ADMIN` | 目前收容所完整有效與歷史詞彙 | 本收容所自訂；平台預設在此頁唯讀 | 本收容所自訂 |
| `STAFF` | 啟用中的詞彙與中文用途 | 不可見 | 不可見 |
| `VOLUNTEER` 或無有效 Context | 不可查看受保護管理資料 | 不可用 | 不可用 |

前端隱藏按鈕只改善體驗，不是授權邊界；API 也必須拒絕不符合角色／收容所範圍的操作。

## 頁面區塊順序

1. 頁面標題「觀察詞彙」與一句用途說明。
2. 四項未篩選摘要：觀察類別、啟用中的選項、收容所自訂選項、已停用或封存選項。
3. 「平台預設」與「收容所自訂」差異說明。
4. 搜尋、類別、狀態、來源篩選與「清除搜尋與篩選」。
5. 目前符合條件的選項數量。
6. 13 個可展開／收合的類別摘要。
7. 具備管理權限時的「新增選項」入口與自訂 option 操作。

## 類別與選項呈現

- 初次進入不展開任何 option；保留類別摘要與計數。
- 類別標題同時呈現中文名稱、次要英文 code、啟用數量、自訂數量、停用／封存數量與展開狀態。
- 展開後先顯示收容所自訂區段，再顯示可獨立收合的平台預設區段。
- option 的第一閱讀層是中文名稱與文字狀態；stable code、來源、說明、最後修改者／時間與歷史使用提示是次要資訊。
- 平台預設顯示「平台預設」且不顯示可修改 action；收容所資料顯示「收容所自訂」。
- 狀態至少使用「啟用中」、「已停用」、「已封存」文字；不可只依色彩、位置或圖示辨識。

## 搜尋與篩選

- 搜尋欄位涵蓋 `display_name`、`code`、`description`；英文 code 不因大小寫而漏結果。
- 類別、狀態、來源條件與搜尋文字採 AND；同一條件內的「全部」代表不限制該維度。
- 摘要卡數字不因搜尋／篩選改變；符合筆數另行顯示。
- 無結果顯示：「找不到符合條件的觀察詞彙，請嘗試清除搜尋文字或放寬篩選條件。」以及「清除搜尋與篩選」。
- 清除後恢復完整資料、摘要與初始收合狀態；不改變任何 option。

## 表單與驗證

「新增選項」與「編輯收容所自訂選項」各自有清楚標題。欄位必須使用可被讀取的標籤：觀察類別、中文名稱、stable code、說明、排序、是否需要補充說明。

- 中文名稱不可空白。
- stable code 使用小寫英文字母開頭，可含小寫英文字母、數字、底線與句點；不得含空白或大寫。
- stable code 必須在目前收容所可見的完整有效詞彙範圍內唯一；重複提示用「目前收容所已有相同 stable code」。
- 未被歷史使用的自訂 code 可依規則修改；已使用 code 顯示唯讀與歷史使用提示。
- 儲存失敗保留輸入；錯誤靠近欄位、以繁體中文說明，並能被螢幕閱讀器取得。
- 成功回饋明確說明「觀察選項已儲存」或「觀察選項已停用／恢復／封存」。

## 生命週期確認

停用／封存 dialog 必須包含選項中文名稱、目前／新狀態、下一次新回報的影響、歷史回報保留說明、「取消」與確認動詞。取消不能改變資料或產生成功訊息。恢復確認要說明恢復後會再次出現在新回報表單，stable code 與歷史快照不變。

## 狀態處理

| 狀態 | 使用者看到的內容 | 可用下一步 |
| --- | --- | --- |
| 載入中 | 「正在載入觀察詞彙…」，不顯示誤導性的零摘要 | 等待或重新載入 |
| 載入失敗 | 錯誤說明與「重新載入」 | 重新載入 |
| 無資料 | 沒有資料的原因與聯絡平台管理者說明 | 具權限者可新增，自訂類別仍需存在 |
| 無搜尋結果 | 友善說明與清除按鈕 | 清除或放寬條件 |
| 權限不足 | 不顯示摘要、數量或選項存在性 | 聯絡管理者 |
| 儲存失敗 | 保留輸入、欄位或全域錯誤、重試 | 修正或重試 |
| 資料已被更新 | 提示最新資料衝突，不靜默覆蓋 | 重新確認後再儲存 |

## Responsive 與可及性

- 桌面版可以使用摘要卡、類別區段與完整次要資訊；手機寬度改用卡片或水平可讀容器，不用壓縮到欄位互相重疊。
- 主要按鈕使用「新增選項」、「編輯」、「停用」、「恢復」、「封存」、「儲存」、「取消」等明確動詞。
- 類別展開控制需暴露 expanded／collapsed 語意；開啟表單或 dialog 後焦點移入，關閉後回到觸發控制。
- 鍵盤可以完成搜尋、篩選、展開、編輯、驗證、排序、狀態轉換與取消。
- 錯誤與成功訊息使用可讀取的 live/status 語意；狀態文字不可只透過 CSS 顏色呈現。
- 互動測試至少覆蓋 320px 左右窄螢幕、一般桌面寬度、Tab 順序、Escape 關閉確認與重新載入錯誤。

## 歷史與來源顯示

- 歷史回報使用 snapshot 的當時中文名稱與 stable code；目前 option 的新名稱不能回填舊回報。
- 已停用／封存的 option 在管理頁可依狀態篩選；Staff 預設只查看啟用中，不因此刪除或隱藏歷史回報。
- 平台預設與收容所自訂的 wire source 可以不同但畫面 label 固定使用台灣繁體中文。
