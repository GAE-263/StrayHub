依角色切換的 LINE 選單

使用者在 LINE 綁定後，後端依角色把不同的底部選單綁到他的 UID。這頁把整個流程演給你看，並列出每個對接點——檔案、端點、環境變數。點左邊的角色，看他會拿到哪套選單、按下去 bot 怎麼回。

✓ 選單框架已建 ✓ 綁定→切換接點已接 ✓ 4 個 LIFF 介面可跑（mock） ⧗ 建立動物端點：後端待實作 ⧗ 真實 LINE 憑證：待提供

整體流程

05

本機試跑

組員照這個就能開起來看
# 一次啟動全部 LIFF 介面 + 本頁
cd StrayHub-main/line-liff
./serve-demo.sh          # 或： python3 -m http.server 8080

# 瀏覽器開：
#   http://localhost:8080/demo/           ← 本展示頁
#   http://localhost:8080/staff-animal/   ← 工作人員動物輸入
#   http://localhost:8080/volunteer/      ← 志工選單
#   http://localhost:8080/adopter/        ← 領養人選單

# 驗證後端選單腳本（dry-run，不需憑證）
cd StrayHub-main
python3 scripts/sync_line_role_menus.py
全部預設 MOCK 模式：不需真實 LINE 憑證或後端就能點、能填、能看流程。送出動作會在 Console 印出 payload。上線只要填好 LIFF_ID / API_BASE_URL，把兩個 MOCK 開關關掉即可。
