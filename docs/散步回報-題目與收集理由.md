# 散步回報　題目與收集理由

內部參考文件 · 2026-08-24 · **這份說明不會顯示在志工的 LINE 畫面上**

志工每次遛完狗，會在 LINE 上回答六個題目。每一題都對應一個實際的照護判斷，不是為了填表而填表。

六題全部有實體依據 —— 看得到、拍得到、有具體行為，**沒有任何一題要求志工推測狗在想什麼**。主觀的觀察集中在自由文字欄位，由 AI 讀取。

---

## 1 · 🚶 散步完成

| | |
|---|---|
| **選項** | 有走完 · 走一半 · 沒走成（懶散不走） |
| **為什麼要收集** | 確認每隻狗都被遛到了。連續幾天沒走成，通常代表人力排班或這隻狗的狀況出了問題。 |
| **該注意的訊號** | 同一隻狗連續三天以上「沒走成」。 |

## 2 · ⚡ 精神體力

| | |
|---|---|
| **選項** | 比平常好 · 跟平常一樣 · 比平常差 |
| **為什麼要收集** | 活力下降常常是生病最早出現的徵兆，比外觀變化更早看得出來。 |
| **該注意的訊號** | 連續「比平常差」，或短期內從「比平常好」掉到「比平常差」。 |

## 3 · 🦵 走路姿勢

| | |
|---|---|
| **選項** | 正常 · 有點怪 · 明顯不對 |
| **為什麼要收集** | 跛行或僵硬多半來自關節、腳掌或外傷，越早發現越好處理。 |
| **該注意的訊號** | 出現「明顯不對」應立即安排檢查，不必等趨勢。 |

## 4 · 💩 大便

| | |
|---|---|
| **選項** | 正常 · 偏軟 · 沒排便 · 有異狀 |
| **為什麼要收集** | 腸胃狀況最直接的指標。軟便連續好幾天，可能是寄生蟲、飲食或壓力造成的。 |
| **該注意的訊號** | 連續「偏軟」超過兩天，或任何一次「有異狀」。 |

## 5 · 🐕 對其他狗

| | |
|---|---|
| **選項** | 友善 · 沒反應 · 緊張或想衝 · 路上沒遇到 |
| **為什麼要收集** | 影響能不能送養到已經有寵物的家庭，也決定籠舍要怎麼安排。 |
| **該注意的訊號** | 長期都是「路上沒遇到」，代表遛狗時段或路線需要調整。 |

## 6 · 🔍 身體外觀

| | |
|---|---|
| **選項** | 沒發現異狀 · 皮膚或毛髮異常 · 傷口或紅腫 · 其他 |
| **為什麼要收集** | 皮膚病和外傷在收容環境很容易擴散，早一天發現就少一批狗遭殃。 |
| **該注意的訊號** | 同一區犬舍短期內多隻出現「皮膚或毛髮異常」。 |

## 關於「今天沒觀察到這項」

每一題底下都有一顆「今天沒觀察到這項」。**它記錄的是「沒有資料」，跟任何一個答案都不一樣。**

刻意不做成普通選項，因為那會變成時間序列上的一個值 —— 但它其實是空的。而且它是最快按的按鈕，混在選項裡一定會被大量濫用。

「路上沒遇到」和「沒排便」則相反，那是**真實的觀察結果**，所以是正式選項。一隻狗連續兩週「路上沒遇到」，代表遛狗路線或時段需要調整；連續兩週「沒觀察到」只代表沒人記錄 —— 兩者要採取的行動完全不同。

## 兩個自由文字欄位

**健康或行為上想補充的** —— 臨床用。例如「左後腳好像不太敢踩」。AI 會讀這欄，判斷是否需要提醒工作人員。

**今天有發生什麼有趣的事嗎** —— 行銷用。追蝴蝶、賴在草地上不走、跟誰變成好朋友都算，之後可以拿來寫送養貼文。

兩者一定要分開存。混在一起的話，行銷同事撈不出可用的故事，AI 也很難分辨「他今天追蝴蝶超可愛」和「他左後腳不太敢踩」哪個是健康訊號。

## 便便照片

大便只要不是「沒排便」，都會請志工拍一張照片，**連「正常」也拍**。

連正常也收集，是為了讓 AI 有足夠的正常樣本當基準 —— 只看過異常的模型會有偏差。照片會跟志工當下選的答案一起存，等於累積一份**有人類標註的資料集**。

可以略過，而且不用交代原因。逼志工說明只會把人推去謊報「沒排便」，那會毀掉更重要的欄位。略過本身仍會被記錄，後台看得到合規率。

## 拿掉了什麼，為什麼

原本的照護回報有 13 題。以下五項在改成散步回報時移除：

**照護完成 · 進食 · 飲水 · 護食** —— 這四項是籠舍照護，不是散步時觀察得到的事。

**情緒** —— 全部欄位裡最主觀的一個。「比平常放鬆」和「跟平常一樣」的界線完全取決於觀察者，同一隻狗不同志工會給出不同答案。對要餵給 AI 判讀趨勢的時間序列來說，評分者之間的變異是雜訊 —— 偵測到的「情緒下降」可能只是「今天換人遛」。而且它跟「精神體力」高度重疊。

真的有異常時，志工仍可在健康補充欄寫「今天一直發抖、看起來很怕」，AI 讀得到。**拿掉的不是記錄情緒的能力，只是強迫每天編碼一次這件事。**

**對人** —— 每天都是同一位志工遛，狗對他的反應本來就穩定，量到的變異多半來自「今天誰帶牠」而不是狗本身。送養媒合需要這個訊號，但那是穩定特質，建議做成獨立的行為評估（每月一次或狀況改變才填），不要塞回每日流程。
